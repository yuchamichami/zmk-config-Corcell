# Corcell DYA Studio 版：接続と使い方

対象はこのリポジトリの `dya-studio` 系ファームです。案内中のキー位置は初期キーマップ基準です。DYA Studio で配列を変更済みの場合は、ご自身の割り当てを確認してください。

## 最初に知っておくこと

- PC と通信する親機は右手側です。USB ケーブルも右手側に挿します。
- 左手側は右手側へ無線で入力を送ります。USB 使用時も左右間は Bluetooth 通信です。左手側にも電源が必要です。
- 「PC で文字が打てること」と「ブラウザの DYA Studio で設定できること」は別です。
- 緑 LED の約 2 秒の点灯は起動の目印です。接続完了や電池残量を知らせる表示ではありません。消灯後も使えます。
- 通常使用や Studio 接続のためにリセットボタンを 2 回押す必要はありません。2 回押す操作はファーム書き込み用です。

| 使用中のファーム | 右 USB で文字入力 | 右 USB で Studio | Bluetooth で Studio | 初期配列の USB／BLE 切替キー |
| --- | --- | --- | --- | --- |
| 2026-09-05 `c2c3cb8` までの DYA 版 | 対応 | 未対応 | 対応。ただしブラウザでの検出に制約あり | なし |
| 現在の `dya-studio` 版 | 対応 | 対応 | 対応 | あり |
| 通常版 `main` | 対応 | 未対応 | 未対応 | 通常版の配列を参照 |

日付だけで判定せず、配布元のブランチ・コミット・ビルドを確認してください。古いファームのままでは、新しいキー操作や USB Studio 接続は使えません。

## 1. 初めて Bluetooth で接続する

1. 左右に単四電池を入れて電源を入れます。最初の切り分けでは USB を外しておきます。
2. 左右を近くに置きます。左右同士は自動で接続します。PC に左右を別々に登録する必要はありません。
3. レイヤー 3 キー（右親指のSpaceと、短押しでAになるキーの間）を押しながら、右上端の Backspace 位置を押し、接続先 0 を選びます。
4. PC／スマホの Bluetooth 設定で新しい機器を追加し、Corcell を選びます。
5. メモ帳などで、右手のキー、左手のキー、トラックボールの順に確認します。

空の接続先を選ぶと、新しい機器とペアリングできます。既に登録された接続先は、その機器への再接続用です。表示されないときは別の空き接続先を試してください。最初から全設定を消す必要はありません。

## 2. USB で使う

1. データ通信対応 USB ケーブルで、右手側と PC をつなぎます。 初回確認ではハブを介さず接続します。
2. 左手側にも電源を入れます。
3. レイヤー 3 キーを押しながら U 位置を押して USB 優先にします。
4. メモ帳などで右手・左手の文字入力を確認します。

USB と Bluetooth の両方が使えるときは、保存された優先出力先が使われます。USB を挿しただけでは Bluetooth 優先を解除できない場合があります。出力先の変更後は、保存のため 10 秒以上待ってから電源を切ってください。

旧版・保存済みの配列で切替キーがない場合： 現在つながっている Bluetooth 接続先を一時的に切断するか、PC 側の Bluetooth を一時的に OFF にして、右 USB で入力できるか確認します。他の登録済み機器に接続している可能性も確認してください。BLE の接続がなくなれば通常は USB に切り替わります。DYA Studio で出力先を「出力なし」に変更していた場合などは、この方法では戻らないため、設定と復旧手順を確認します。

## 3. DYA Studio で設定する

<a id="usb-接続接続改善版"></a>

### USB 接続

1. 右手側を PC に USB 接続し、上記の操作で USB 優先にします。
2. PC の Chrome または Edge で [DYA Studio](https://studio.dya.cormoran.works/) を開きます。
3. USB 接続を選び、Corcell のシリアルポートを選択します。ポート名の表示は OS により異なります。XIAO のコンソール用と Studio 用の 2 ポートが出る場合があります。一方で応答がない場合は接続を閉じ、もう一方を選んでください。
4. キーやレイヤーを編集し、保存を実行します。設定画面ごとに保存が必要な場合があります。
5. 保存完了を確認し、10 秒以上待ってから再起動して変更が残ることを確認します。

このブランチは Studio のロックを無効にしているため、USB 接続では解除操作は不要です。接続候補が出ないときは、下の切り分け表を確認してください。

<a id="bluetooth-接続旧-dya-版でも利用可能"></a>

### Bluetooth 接続

1. 先に OS の Bluetooth 設定で Corcell をペアリングし、その PC で文字が打てることを確認します。
2. USB を外すか、レイヤー 3 ＋ I 位置で Bluetooth 優先にします。文字の出力先と Studio の接続方式を合わせます。
3. レイヤー 3 ＋右親指の短押し A の位置の `studio_unlock` を押します。この操作で、ブラウザからCorcellを見つけられるようになります。
4. [DYA Studio](https://studio.dya.cormoran.works/) の Bluetooth 接続から Corcell を選びます。
5. 編集後に保存します。

2026-09-05 `c2c3cb8` までの DYA 版は、OS 接続後に広告が止まり、ブラウザの選択画面に Corcell が出ない環境があります。この版では解除キーを押しても広告を再開しません。文字が打てる場合は、ペアリングを消す前にファームの版を確認し、現在の `dya-studio` へ更新してください。

ブラウザ・OS の Web Bluetooth 対応にも左右されます。DYA の公開説明ではデスクトップ Chrome／Edge、Android Chrome、iOS の Bluefy が挙げられています。Safari／Firefox での Studio 接続は案内対象外です。候補が出ない・不安定な場合は、PC の USB 接続を試してください。通常の Bluetooth キーボード入力に、DYA Studio や対応ブラウザは不要です。

### 使う画面と注意点

- キーマップ： キー・レイヤーを変更します。接続用のレイヤー 3 キーと出力切替キーは残すと復旧しやすくなります。
- トラックボール： `cursor` と `scroll` の倍率を調整します。初期値はそれぞれ 0.4 倍と 0.1 倍です。出荷品のボールは右側のみです。左側へボールを追加した場合は、同じ倍率が適用されます。
- 接続： Bluetooth の接続先・優先出力先などを確認します。接続先や出力を切り替えると、編集中の Studio 接続も切れることがあります。先に保存してください。
- 設定： idle／sleep の設定などを扱います。ファームの既定値は idle 30 秒、deep sleep 15 分です。
- 診断： 表示可能な機器情報や状態を、問い合わせ時の資料として利用できます。

DYA Studio にある機能すべてが Corcell のセンサーで使えるとは限りません。PAW3222 のハードウェア CPI 変更やセンサー画像取得は、この構成では対応確認していません。また自動マウスレイヤーの起動は別の固定 processor が担当するため、Studio の runtime processor の自動レイヤー設定だけでは、その固定動作を停止できません。

## 4. 接続操作の早見表

[初期キーマップの全体図](../keymap-drawer/corcell.svg) も参照してください。

すべて 右親指のレイヤー 3 キーを押しながら操作します。表の文字は入力される文字ではなく、初期配列でのキー位置です。

| 押す位置 | 動作 | 対応 |
| --- | --- | --- |
| U | USB 優先 | 現在の `dya-studio` の初期配列 |
| I | Bluetooth 優先 | 現在の `dya-studio` の初期配列 |
| 右上端 Backspace | 接続先 0 を選ぶ | 旧 DYA 版から共通 |
| 右端 Enter | 接続先 1 を選ぶ | 同上 |
| 右端 `?` | 接続先 2 を選ぶ | 同上 |
| 右下端 → | 接続先 3 を選ぶ | 同上 |
| Y | 選択中の接続先のペアリング情報を消す | 同上 |
| 右親指の短押し A の位置 | Studio Unlock。現在の `dya-studio` ではブラウザ検出を開始 | キーは旧版にも存在。旧版では検出開始の設定なし |

内部番号は 0 始まりです。Studio の表示が 1 始まりの場合は、内部 0 が表示上の 1 番目になります。接続先を選ぶ操作と、USB／Bluetooth の優先出力を選ぶ操作は別です。

## 5. トラックボール・スリープ

左手だけがディープスリープ後にキーで復帰せず、リセットが必要な場合は、[スリープ不具合の修正・更新手順](../README.md#スリープ不具合の修正版へ更新する)を確認してください。

- 通常はカーソル移動です。操作中は自動でマウスレイヤー 4 が有効になり、J＝左クリック、K＝中央クリック、L＝右クリックになります。最後の操作から約 700 ms で解除される設定です。
- I、または右親指の短押し A のキーを長押しするとレイヤー 5 に入り、ボール操作がスクロールになります。Shift との併用で横スクロールになります。
- エンコーダーの初期動作は音量調整です。
- 長時間放置後は、キーを一度押してから数秒待ち、もう一度入力してください。復帰の最初のキーが文字入力にならないことがあります。
- 起動 LED と電池残量は別です。残量表示は Ni-MH 電池向けの電圧換算値で、厳密な残り時間ではありません。電池種類や負荷にも影響されます。

## 6. 反応しないときの切り分け

| 症状 | 確認する順番 |
| --- | --- |
| `The port is already open` | 下の「Studio でポートが既に開いている」を参照。まずタブと接続状態を整理し、全設定初期化はしない |
| Windows のコピーで `0x80070022` | 下の「Windows の書き込みエラー」を参照。再起動後の動作とファーム版で成否を確認 |
| USB で文字が打てない | 右側に挿したか → データ対応ケーブル・別のポート → ファーム書き込みモードになっていないか → USB 優先 → Bluetooth 接続を一時切断 |
| 文字は打てるが USB Studio の候補がない | 旧 DYA 版／通常版ではないか → Chrome／Edge か → 右側の通常起動か |
| ポートは見えるが Studio が応答しない | USB Studio 対応版か（旧版にもコンソール用ポートはある） → 2 ポート出る場合はもう一方を選択 → USB 優先か → 他の Studio タブやシリアル接続アプリを閉じる → 再接続。Linux ではシリアルポートの利用権限も確認 |
| Bluetooth の候補が出ない | 右側の電源 → 空き接続先の選択 → 既に別端末に接続していないか。OS のペアリング画面と Studio の選択画面を混同しない |
| ペアリング済みなのに文字が出ない | 選択中の接続先 → USB に出力していないか → スリープ復帰待ち → 下記の再ペアリング |
| 右は動くが左だけ動かない | 左の電源・電池 → 左右を近づける → 左右に正しいファームが入っているか → 両側再起動 → 最後に左右の設定初期化 |
| 両方の文字は打てるがボールだけ動かない | DYAの倍率・レイヤー設定 → 書き込んだファームを確認。スリープ後だけ動かない場合は復帰修正版へ更新 |
| 書き換えたのに新しい配列にならない | Studio で保存した配列が優先されていないか。下記「保存済み配列がある場合」を参照 |
| USB ドライブとして表示される | 書き込みモードです。正しい UF2 を書き込むか、リセットボタンを 1 回押して通常起動させます |

USB ケーブルだけで左右間を有線接続する構成ではありません。左手 USB に挿すだけで左手を単独の有線キーボードとして使うこともできません。

### Studio で「The port is already open」と出る

`Failed to execute 'open' on 'SerialPort': The port is already open.` は、ブラウザが閉じていないシリアルポートを再度開こうとした際のエラーです。接続失敗後にポートが残った、接続操作が重なったなどの可能性があります。これだけではキーボードの故障やファーム破損とは判断できません。

1. 接続ボタンの連打をやめ、画面に接続中／再接続中の表示があればキャンセルします。
2. DYA Studio の通常版・dev preview・ZMK Studio のタブをいったんすべて閉じます。シリアル接続アプリも閉じます。
3. USB を抜き差しして右手を通常起動させ、PC の Chrome／Edge で通常版の DYA Studio を 1 タブだけ開きます。
4. USB 対応ファーム・USB 優先を確認し、接続操作を 1 回行います。複数ポートが出る場合は Studio 用を選びます。
5. 続く場合はブラウザを完全終了して開き直します。それでも同じなら、URL・ブラウザ版・操作順・エラーを記録して相談してください。

この文言はブラウザ内部のポート状態を表し、「必ず別アプリが占有している」という意味ではありません。他アプリとの競合も一般的な接続失敗の原因になるため、切り分けとして閉じます。旧ファームの USB Studio 非対応は別問題で、ブラウザのエラーを解消しても対応ファームへの更新は必要です。

### Bluetooth がリセット後だけ見つかる

再起動で一時的に接続・広告の状態が変わり、ブラウザから見つかる場合があります。ただし、その現象だけから「毎回両側のリセットが必要な仕様」とは判断できません。キーボードへの通常の Bluetooth 接続と、Studio の機器選択を分けて確認してください。

現在の `dya-studio` では、OS との接続を確認してから、レイヤー 3 ＋右親指の A 位置の `studio_unlock` でブラウザ検出を開始します。初期配列ではレイヤー 3 ＋左上端 Esc 位置にも同じ動作があります。右側のキーなら、左との接続状態に関係なく操作できます。繰り返し再起動が必要なら、そのとき文字入力もできないのか、Studio の候補だけ出ないのかを記録してください。

### 通常版と dev preview のどちらを開くか

[通常版 DYA Studio](https://studio.dya.cormoran.works/)を使ってください。dev preview は開発中の版で、常により安定しているとは限りません。比較のために試す場合は通常版のタブを閉じ、DYA Studio の公式ページにある dev preview リンクから開き、URL と確認結果を記録してください。画面の版を変えても、ファームにない USB Studio 機能は追加されません。

## 7. PC／スマホとのペアリングをやり直す

1. Corcell でやり直す接続先番号を選びます。
2. OS の Bluetooth 設定から、その Corcell の登録を削除します。
3. Corcell でレイヤー 3 ＋ Y 位置を押し、選択中の接続先をクリアします。
4. OS から再度 Corcell を追加します。
5. 文字入力を確認し、10 秒以上待ってから電源を切ります。

これは PC／スマホとの登録をやり直す操作です。左右間の登録を初期化する操作ではありません。すべての設定を消す `settings_reset` は、これで解決しない場合の最終手段です。

## 8. ファーム更新

1. [READMEのダウンロード](../README.md#ファームのダウンロード)を開きます。
2. 左右用のZIPをダウンロードし、展開します。GitHubへのログインは不要です。
3. 保存済みの配列や設定を記録します。Studio でエクスポートできる項目は退避し、ほかは画面や数値を控えます。
4. 書き込む側をデータ対応 USB ケーブルで接続し、XIAO のリセットボタンを素早く 2 回押します。
5. 出てきた USB ドライブに、その側の UF2 を 1 ファイルだけコピーします。左右と settings_reset をまとめてコピーしません。完了後にドライブが消え、再起動します。
6. 右手には `Corcell_R-dya-studio-xiao_ble_zmk.uf2`、左手には `Corcell_L-dya-studio-xiao_ble_zmk.uf2` を使います。通常版と DYA 版を混ぜず、基本は同じビルドの左右をそろえます。
7. 右 USB での文字入力、Studio、Bluetooth、左手入力、ボールを確認します。

2026年11月1日のスリープ復帰修正は、左右両方を更新してください。`settings_reset`は不要です。[更新後の確認方法](../README.md#スリープ不具合の修正版へ更新する)に沿って、左右の文字入力と右ボールの復帰を確認します。

### ファイル名・配布元の確認

このリポジトリの現在の命名では、`Corcell_L-xiao_ble_zmk.uf2`／`Corcell_R-xiao_ble_zmk.uf2` は通常版、`Corcell_L-dya-studio-xiao_ble_zmk.uf2`／`Corcell_R-dya-studio-xiao_ble_zmk.uf2` は DYA 版です。DYA Studio を使う場合は後者の配布元を確認してください。

ただし、古い命名・改名・派生ファームもあり得るので、ファイル名だけでは断定できません。ダウンロードした Build URL とブランチを合わせて確認します。Windows に表示されるファイル更新日時だけではビルドを特定できません。

### Windows の書き込みで「0x80070022」と出る

このコードは Windows のドライブ／媒体に関するエラーです。UF2 の書き込み完了で基板が再起動し、書き込み用ドライブが消える動作は正常です。その切断のタイミングで Windows のコピー画面にエラーが残る可能性がありますが、このエラーが出れば必ず成功、とは言えません。

1. コピー処理がエラーダイアログで止まったら、再試行を連打せず数秒待ちます。処理中にケーブルを抜かないでください。
2. ドライブが消えて通常起動した場合は、残ったダイアログをキャンセルし、右 USB の文字入力、左右入力、Studio に表示できる場合は機器情報のファーム版を確認します。起動 LED だけ、あるいは文字が打てるだけでは、旧ファームから更新できたことまで証明できません。
3. 起動しない／更新版と確認できない場合は、ブラウザ等を閉じ、ZIP を PC 内のフォルダに展開し直します。書き込みたい側のドライブを開き直して、正しい UF2 を 1 個だけコピーします。必要に応じてデータケーブル・USB ポートも変えます。
4. 再発時は、コピー先のドライブ名、左右どちらか、ファイル名と Build URL、コピー前後にドライブがどう変化したかを記録して相談します。この表示だけを理由にドライブをフォーマットしたり、ブートローダーを更新したりする必要はありません。

`settings_reset` を書いた場合は、その後に左右それぞれの通常ファームを書き込むまで文字入力の確認はできません。書き込み用ドライブを開き直す操作と、ペアリングや全設定の初期化は別です。

### 保存済み配列がある場合

通常の UF2 更新ではペアリングや Studio 設定は残ります。そのため、新しい初期配列の USB／BLE キーも自動では追加されない場合があります。

USB／Bluetooth切替キーがない場合は、Studioでレイヤー 3 の U 位置へ `&out OUT_USB`、I 位置へ `&out OUT_BLE` に相当する出力動作を割り当てて保存してください。StudioへはUSBを外してBluetoothでつなぐか、Bluetoothを一時切断してUSBでつなぎます。初期配列へ戻す場合は、記録を取ったうえで Studio のキーマップ初期化を使います。全設定初期化とは消える範囲が違うので、確認画面を読んでから実行してください。

### 最終手段：左右の設定初期化

ペアリング、保存済み配列、ポインタ設定などが消えます。 初回接続や通常更新の必須手順ではありません。

1. 左右の UF2 と `settings_reset-dya-studio-xiao_ble_zmk.uf2` を先に用意し、設定を記録します。
2. 左右それぞれに `settings_reset` を書き込み、各側で通常起動させて初期化を実行します。コピー直後に電源を抜かず、数秒待ちます。
3. 再び書き込みモードに入り、右に R、左に L の通常の DYA ファームを書き込みます。`settings_reset` のままではキーボードとして使えません。
4. 両側を再起動して近くに置き、左右の自動接続を待ちます。
5. PC／スマホ側でも古い Corcell 登録を削除し、最初の Bluetooth 接続手順からやり直します。
