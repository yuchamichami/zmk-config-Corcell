ボトムケースの手前側に爪があります。
手前のフレームを引っ張り、ボトムケースの爪をフレームの穴から外してください。

戻すときは、先に手前側の爪をフレームの穴に入れ、
そのあと奥側の爪をフレームにはめます。

## マグネットの取り付け

ボトムケースの内側に、マグネットを入れる穴があります。

**マグネットの向きを間違えると、取り外せなくなります。**
アロンアルファなどの接着剤で固定すると確実ですが、間違えたときにやり直せません。
心配な場合は、マグネットを穴に入れたうえからマスキングテープなどで貼り付けて
仮固定してください。接着剤より磁力は落ちるものの、間違えても後戻りできます。

## チルトスタンドのサポート材除去

チルトスタンド部分は、3D プリントのサポート材が残った状態でお届けします。

**チルトスタンドを使わない場合は、そのままお使いいただけます。**
使う場合は、下記の手順で取り除いてください。

https://github.com/user-attachments/assets/3976ca60-955a-4a11-b60c-074f46f67fc4

1. ニッパーの先をサポート材に突き刺します。
2. サポート材だけをつまんで引っ張ると、サポート材が外れます。
3. 小さな破片が残った場合は、ダイヤモンドヤスリなどで削り取ってください。
   100 円ショップのもので十分です。
4. サポート材を取り除いたら、チルトスタンドを貼り付けてください。

フィラメントの状態や外しかたによっては、サポート材が残ることがあります。
うまく外せない場合は、個別にご連絡ください。
