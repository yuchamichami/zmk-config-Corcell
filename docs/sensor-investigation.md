# DYA版センサー不動の調査（2026-09-18）

確認できた実機状況: ユーザーの同じ右側センサーはmain版で動き、DYA版では動かない。左側は未検証。接続方式・保存されたポインタ設定は未確認。

動作したmainのビルド33941646874とDYAのビルド35293812954を比較:

- ZMK: e5c9b69、Zephyr: 7c6b4cc4、PAW3222: fc94676で一致。
- 右PAW3222・SPI・ポインティング・USBマウス出力はどちらも有効。
- センサーのピン・SPI周波数は一致。
- mainは標準の反転・スケーラー、DYAは保存設定を読み込むruntime input processorを使う。
- DYAのコンパイル時初期値はXY反転・倍率2/5・回転0。初期値だけで全停止する理由は見つかっていない。

## 切り分け用右側ファーム

`Corcell_R-dya-sensor-baseline-xiao_ble_zmk.uf2`はDYAのキーマップ・Studio・Bluetooth設定を残し、左右センサーの入力処理だけをmainと同じ構成に置き換える。通常版とは別の診断用成果物。

1. 現在のDYA設定・配列は必要に応じてバックアップする。
2. **右側だけ**に上記ファームを書き込み、同じ接続方式でセンサーを確認する。settings_resetは不要。
3. これで動けばruntime入力処理・保存設定側に原因を絞れる。動かなければ、処理以外や接続先の問題を続けて調べる。USBとBluetoothの結果は分けて記録する。

診断版ではDYA Studioの感度・回転などの調整はセンサー出力に反映されない。設定を削除する処理は追加していない。通常のDYA右側ファームに戻すとruntime処理に戻る。

これは原因切り分け用で、実機で解決済みとはしていない。センサー不動の根本原因確定前に通常DYAファームの処理は置き換えない。
