# 30秒ディープスリープ・復帰テスト

`Corcell_R-dya-sleep-test-30s-xiao_ble_zmk.uf2` を右、
`Corcell_L-dya-sleep-test-30s-xiao_ble_zmk.uf2` を左へ書き込みます。
settings_reset は不要です。通常版の待ち時間は変更していません。

1. USBを両側とも抜き、電池で起動してBLE接続とキー・センサー動作を確認。
2. キー・ボール・エンコーダに触らず、35～40秒待つ。
3. まず右の通常キーを押し、BLE再接続とキー入力・右センサーが戻るか確認。
4. 左も通常キーを押して起こし、左キー・左センサーを確認。
5. これを数回繰り返す。リセットや電源スイッチ操作は復帰テストには使わない。

設定は無操作5秒でidle、約30～31秒でdeep sleepです。30秒はidleに入って
からではなく、最後の入力から数えます。USB給電中はdeep sleepに入りません。
センサーから入力が続く場合はタイマーが更新され、眠れません。
両側が眠った場合、片側のキーだけで反対側も起きるとは限りません。
ボールだけでの復帰を前提にせず、通常キーで試してください。

既存の起動LEDは復帰時にも点灯する想定です。LEDやBLE切断だけで
消費電流・全周辺回路のスリープ成立を証明するものではありません。

DYAで保存された待ち時間よりテスト設定を優先しますが、上書きはRAMだけです。
テスト中はDYA Studioのスリープ設定を操作しないでください。
終了後は通常の `Corcell_R-dya-studio-xiao_ble_zmk.uf2` と
`Corcell_L-dya-studio-xiao_ble_zmk.uf2` に戻します。元の保存設定があれば復元され、
なければ通常の15分設定になります。ペアリング・キーマップの消去は不要です。

ビルドによる検証と実機の復帰検証は別です。実機の消費電流と復帰は未検証です。
